# Machine Learning Datasets Collection

A curated collection of standard and popular datasets commonly used for training, benchmarking, and experimenting with Machine Learning and Deep Learning models. This repository serves as a centralized, easily accessible data source for various ML tasks including regression, classification, and exploratory data analysis (EDA).

---

## 📊 Included Datasets

The repository currently contains the following datasets in CSV format:

| Dataset File | Description | Common Use Case |
| :--- | :--- | :--- |
| `Iris.csv` | The classic multi-class dataset containing features of three iris flower species. | Classification |
| `boston_house_prices.csv` | Housing data from Boston suburbs, including structural, environmental, and neighborhood features. | Regression |
| `diabetes.csv` | Patient clinical data used to predict the onset of diabetes based on diagnostic measurements. | Binary Classification |
| `train.csv` | General training data structured for exploratory analysis and model building. | Classification / Regression |
| `data.csv` | Generic multi-purpose dataset for feature engineering and baseline testing. | General ML / EDA |
| `ipl-matches.csv` | Historical match data from the Indian Premier League, perfect for sports analytics and pattern mining. | Data Analytics / EDA |

---
